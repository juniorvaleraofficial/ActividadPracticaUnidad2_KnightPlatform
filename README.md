# Actividad Práctica Unidad 2 - Knight Platform

Proyecto desarrollado en Unity como parte de la asignatura **Programación de Videojuegos**.

## Descripción

Juego de plataformas 2D donde el jugador controla un caballero que puede:

- Moverse hacia la izquierda y derecha.
- Saltar entre plataformas.
- Utilizar animaciones de Idle, Run y Jump.
- Interactuar con colisiones y gravedad.
- Llegar a una meta para completar el nivel.
- Reiniciar la partida al finalizar.

## Tecnologías utilizadas

- Unity 6
- C#
- Rigidbody2D
- BoxCollider2D
- Animator
- Sprites 2D
